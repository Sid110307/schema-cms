## Default Permission

Allows all schema-cms commands.

#### This default permission set includes the following:

- `allow-configure`
- `allow-launch-config`
- `allow-list-files`
- `allow-read-file`
- `allow-save-files`
- `allow-media-info`
- `allow-pick-media`
